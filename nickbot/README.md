# 🔨 NickForge — Telegram-бот для подбора ников

<img src="botfather/avatar.png" width="96" align="right" alt="NickForge">

Отправляешь боту слово, имя или фразу — получаешь удобные и похожие ники.

- 🎯 **Точные** — `Иван Петров` → `ivanpetrov`, `ivan_petrov`, `ipetrov`
- 🪞 **Похожие** — замены звуков и букв, удвоения, leet: `kotik` → `cotik`, `kootik`, `ko7ik`
- ➕ **С приставками** — `imkotik`, `kotik_x`, `thekotik`, `kotikov`
- ✂️ **Короткие** — `telegram` → `tlgrm`, `telegr`
- 🔍 **Проверка занятости** — 🟢 скорее свободен / 🔴 занят
- ✨ **Стильные ники** для имени, игр и соцсетей — `꧁Котик꧂`, `𝓚𝓸𝓽𝓲𝓴`, `ᴋᴏᴛɪᴋ`, `🅺🅾🆃🅸🅺`
- 🎲 **Случайные ники**, если идей нет
- ⚙️ **Настройки**: длина 5–32, с цифрами или без, с «_» или без
- 💬 **Inline-режим**: `@NickForgeBot слово` в любом чате

Понимает русский, украинский и английский (кириллица транслитерируется).
Все варианты соответствуют правилам Telegram: 5–32 символа, `a–z 0–9 _`,
начинаются с буквы, без `__` и `_` в конце.

## Быстрый старт

```bash
cd nickbot
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # Windows: copy .env.example .env
# вставь в .env токен от @BotFather

python botfather/setup_profile.py  # один раз: имя, описание, команды, аватарка
python bot.py
```

Как создать бота и что куда вписать в BotFather — в **[botfather/BOTFATHER.md](botfather/BOTFATHER.md)**.

## Команды

| Команда | Что делает |
|---|---|
| *любой текст* | подбор username |
| `/nick слово` | то же самое |
| `/style текст` | стильные ники (шрифты Unicode, украшения) |
| `/check ник1 ник2` | проверить до 10 ников |
| `/random` | случайные ники |
| `/settings` | длина, цифры, подчёркивания |
| `/help` | помощь и правила username |

Под каждой подборкой есть кнопки **🔄 Ещё**, **🔍 Проверить**, **✨ Стильные**, **⚙️ Настройки**.
Нажатие на ник копирует его.

## Как работает проверка «свободен ли ник»

В Bot API нет метода «проверить username», поэтому бот смотрит публичную
страницу `https://t.me/<ник>`: если там есть профиль, канал или бот — ник занят.
Это быстро, но **приблизительно**: ники, выставленные на продажу на Fragment
или зарезервированные Telegram, могут показаться свободными. Точный ответ —
при попытке поставить ник в настройках Telegram. Выключить проверку:
`CHECK_AVAILABILITY=0` в `.env`.

## Структура

```
nickbot/
├── bot.py                  # точка входа
├── nickbot/
│   ├── generator.py        # генерация и ранжирование username
│   ├── styles.py           # стильные ники (шрифты, украшения)
│   ├── checker.py          # проверка занятости через t.me
│   ├── handlers.py         # команды, кнопки, inline-режим
│   ├── texts.py            # тексты сообщений
│   ├── profile.py          # имя, описания, команды для BotFather
│   └── config.py           # чтение .env
├── botfather/
│   ├── BOTFATHER.md        # пошагово: что заполнить в @BotFather
│   ├── avatar.png          # аватарка 640×640
│   ├── description.png     # картинка описания 640×360
│   ├── generate_assets.py  # перерисовать картинки
│   └── setup_profile.py    # заполнить профиль бота через Bot API
└── tests/
```

## Заметки

- Настройки и последнее слово пользователя хранятся в памяти — база не нужна.
  После перезапуска бот просто попросит отправить слово заново.
- Для 24/7 работы запускай `python bot.py` на сервере/VPS (systemd, screen, Docker)
  или на любом хостинге Python-ботов.
