# 🔎 NickForge — проверка ников в Telegram + ИИ-подбор

<img src="botfather/avatar.png" width="96" align="right" alt="NickForge">

**Главное:** отправляешь боту ник — он говорит, занят он или нет, а если ник не по
формату — объясняет почему.

```
🔴 @xlebb — занят
🟢 @xleb_free — свободен
💎 @money — на Fragment — только покупка
❌ xleb_ — не по формату: не может заканчиваться на «_»
❌ хлеб — не по формату: кириллица не разрешена (например, khleb)
❌ xleb — не по формату: слишком короткий: 4 симв., нужно минимум 5
```

- можно сразу несколько ников (до 20): через пробел, запятую, с `@` или ссылкой `t.me/…`;
- **🤖 ИИ-подбор** (`/ai`): описываешь словами, какой ник нужен («что-то про хлеб,
  коротко», «похожий на @xlebb, но свободный»). ИИ (Claude) придумывает осмысленные,
  не шаблонные варианты, **сам проверяет их через бота**, отбрасывает занятые и пробует
  ещё. В ответе — его варианты и полный список того, что он проверил. Можно уточнять:
  «короче», «без цифр», «ещё варианты»;
- под проверкой занятого ника есть кнопка **«🤖 Найти похожие свободные»**;
- inline-режим: `@NickForgeBot xlebb` в любом чате.

ИИ работает только когда ты его включил и о чём-то попросил: в фоне он ничего
не делает, за один запрос — максимум 5 раундов и 60 проверок.

## Быстрый старт

```bash
cd nickbot
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # Windows: copy .env.example .env
# впиши в .env BOT_TOKEN (обязательно), ANTHROPIC_API_KEY (для ИИ) — см. ниже

python botfather/setup_profile.py  # один раз: имя, описание, команды, аватарка
python bot.py
```

Как создать бота и что куда вписать в BotFather — **[botfather/BOTFATHER.md](botfather/BOTFATHER.md)**.

## Настройки (`.env`)

| Переменная | Нужна? | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `ANTHROPIC_API_KEY` | для ИИ | ключ Claude API с [console.anthropic.com](https://console.anthropic.com). Без него `/ai` выключен, проверка работает |
| `AI_MODEL` | нет | модель, по умолчанию `claude-opus-5-5` |
| `AI_EFFORT` | нет | `low` / `medium` / `high` — насколько глубоко ИИ думает (по умолчанию `medium`) |
| `AI_DAILY_LIMIT` | нет | ИИ-запросов в день на одного пользователя (по умолчанию 20) |
| `AI_ALLOWED_USERS` | нет | Telegram ID через запятую, кому можно ИИ. Пусто — всем |
| `TG_API_ID`, `TG_API_HASH` | для точной проверки | см. ниже |

ИИ-запросы платные (оплачивает владелец ключа), поэтому есть дневной лимит и список
допущенных пользователей. Для экономии можно поставить `AI_MODEL=claude-sonnet-5-5`
или `AI_EFFORT=low`.

## Точная проверка (рекомендую)

Bot API не умеет проверять ники, поэтому без настройки бот смотрит публичные страницы
`t.me/<ник>` и `fragment.com`. Это работает, но ники, которые Telegram зарезервировал или
скрыл, могут показаться свободными (бот пишет «скорее всего свободен»).

Для **точной** проверки бот может спрашивать сам Telegram — тем же способом, что и поле
username в настройках (`account.checkUsername`). Для этого нужен обычный Telegram-аккаунт:

1. Зайди на [my.telegram.org](https://my.telegram.org) → **API development tools** → создай
   приложение, скопируй `api_id` и `api_hash` в `.env` (`TG_API_ID`, `TG_API_HASH`).
2. Один раз выполни `python login.py` — введи телефон и код из Telegram.
   Появится файл `checker.session` (это доступ к аккаунту — никому не давай, он в `.gitignore`).
3. Перезапусти бота — в логе будет «Точная проверка ников через Telegram включена».

Лучше взять отдельный аккаунт: Telegram ограничивает частоту таких проверок. Если лимит
сработает, бот на время сам переключится на проверку по t.me.

## Команды

| Команда | Что делает |
|---|---|
| *ник или несколько* | проверка |
| `/check ник1 ник2` | то же самое (удобно в группах) |
| `/ai` | включить ИИ-подбор, дальше просто пиши, что нужно |
| `/ai описание` | сразу запустить ИИ-подбор |
| `/ai off` | выключить ИИ |
| `/help` | статусы и правила username |

## Структура

```
nickbot/
├── bot.py                  # точка входа
├── login.py                # вход в Telegram-аккаунт для точной проверки
├── nickbot/
│   ├── username.py         # разбор ников из текста и проверка формата с причинами
│   ├── checker.py          # занят/свободен: Telegram-аккаунт или t.me + Fragment
│   ├── ai.py               # ИИ-подбор: Claude + инструмент check_usernames
│   ├── handlers.py         # команды, кнопки, inline-режим
│   ├── texts.py            # тексты сообщений
│   ├── profile.py          # имя, описания, команды для BotFather
│   └── config.py           # чтение .env
├── botfather/              # аватарка, картинка описания, тексты и setup_profile.py
└── tests/
```
